# Academic Publication Tracker

An open-source desktop app for finding publications, tracking citations, and organizing research.

**v0.5.0 is prepared as a draft**, pending launch checks of the signed Mac candidates.

**Download the latest published version, v0.4.3:**

- [macOS — Apple Silicon](https://github.com/ausmeyer/academic_publication_tracker/releases/download/v0.4.3/Academic-Publication-Tracker-0.4.3-mac-arm64.dmg)
- [macOS — Intel](https://github.com/ausmeyer/academic_publication_tracker/releases/download/v0.4.3/Academic-Publication-Tracker-0.4.3-mac-x64.dmg)
- [Windows — x64](https://github.com/ausmeyer/academic_publication_tracker/releases/download/v0.4.3/Academic-Publication-Tracker-0.4.3-win-x64.exe)

Mac apps are signed and Apple-notarized. Windows is an unsigned preview.
