# Academic Publication Tracker

An open-source desktop app for finding publications, tracking citations, and organizing research.

**Download v0.5.0:**

- [macOS — Apple Silicon](https://github.com/ausmeyer/academic_publication_tracker/releases/download/v0.5.0/Academic-Publication-Tracker-0.5.0-mac-arm64.dmg)
- [macOS — Intel](https://github.com/ausmeyer/academic_publication_tracker/releases/download/v0.5.0/Academic-Publication-Tracker-0.5.0-mac-x64.dmg)
- [Windows — x64](https://github.com/ausmeyer/academic_publication_tracker/releases/download/v0.5.0/Academic-Publication-Tracker-0.5.0-win-x64.exe)

Mac apps are signed and Apple-notarized. Windows is an unsigned preview.
